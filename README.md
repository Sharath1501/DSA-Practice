# DSA-Practice

This repository contains my Data Structures and Algorithms (DSA) practice code, along with some Machine Learning and Computer Vision experiments.

## Project Structure

The project is a mix of C++, Python, and Java implementations.

### C++ (DSA)
Contains various DSA implementations including:
- Graph algorithms (`graph.cpp`)
- Dynamic Programming (`subsetsum.cpp`)
- String manipulation (`str.cpp`)
- Basic I/O and patterns (`inout.cpp`, `pattern.cpp`)

### Python (ML & CV)
Includes scripts for Object Detection and Tracking:
- `app.py`, `app1.py`: Application entry points.
- `combined.py`, `combinedbar.py`: Likely scripts for combining model outputs or visualization.
- `yolov8s.pt`: YOLOv8 small model weights for object detection.
- Performance analysis plots (`optimized_deep_sort_performance.png`, etc.).

### Java
- Basic Java class files (`start.java`).

## Setup

### Prerequisites
- C++ Compiler (g++)
- Python 3.x
- Java JDK

### Running Python Scripts
It is recommended to use a virtual environment.
```bash
# Activate existing env (if applicable) or create new
python -m venv env
source env/bin/activate # or env\Scripts\activate on Windows
pip install -r requirements.txt # (If requirements.txt exists)
```
